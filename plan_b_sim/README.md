# Plan B 公式仿真

三条路线，没有实测。效果表里的数只来自这个程序的日志。

在仓库根目录运行：

```bash
python3 -m plan_b_sim
```

需要 NumPy。同一条命令再跑一次，表里的数字不变。

## 算的是什么

器件是论文第二章那颗压电宽度伸张谐振器：宽 143 μm，硅厚度只有 20、40、60 μm 三档，上面是 1 μm 掺钪氮化铝、0.15 μm 钼、0.2 μm 氧化硅。频率用论文式 (2-1) 到 (2-9)，再按表 2-1 的热膨胀把宽度和密度随温度改掉。热路是一阶的：

C dT/dt = P − (T − T环境) / Rth

Rth 用论文 COMSOL 公布的 3.85 ℃/mW，热时间常数用公布的 37 ms。从 −40 ℃ 到 110 ℃ 的稳态功率因此等于温差除以这个热阻。这是在核对积分器，效果表里的能耗仍是功率沿轨迹的积分。

环境从 −40 ℃ 走到 105 ℃，再走回来。前 2 秒环境停在 −40 ℃，用来看加热能不能进 110±1 ℃。控制器只有一种，主动和一起做共用：速度式 PI，功率不小于 0，也不超过该候选的功率上限。

三行的模型调用次数相同。一次调用是频率公式求一次值，或热路积分一步。频率查表的插值不再另计。被动只有三档厚度，算完以后按原轨迹重复跑，直到次数和另外两行一样。

## 和论文有限元拐点

程序会把 20、40、60 μm 的过零温度写进 `output/summary.json` 的 `frequency_check`。论文有限元大约是 89 ℃、112 ℃、138 ℃。闭式公式的过零比这三档高，而且在这条公式里是局部极大。没有改符号，也没有乘系数去凑那三个数。对不上的差留在 `gap_vs_thesis_fem_c`。

## 效果表

`output/effect_table.md` 是五列：拐点误差、来回过程的剩余频率偏差、加热能耗、停稳时间、调用次数。被动不加热，停稳时间写「不加热」。论文里的 ppb、品质因数和流片结果不在这张表里。

排序先看剩余频率偏差，差距小于 0.0001 ppm 的视为同一档，然后看能耗，再看拐点离 110 ℃ 的距离。公布的那一行用频率公式重算，不用插值。
